Schritt-für-Schritt: Telegram Bot kostenlos einrichten

So erstellst du deinen eigenen Telegram-Bot mit kostenloser Gemini KI:

1

Telegram Bot erstellen (kostenlos)

Öffne Telegram und suche nach @BotFather (dem offiziellen Telegram-Bot-Ersteller):

  1. Starte den Chat mit @BotFather
  2. Sende den Befehl /newbot
  3. Gib deinem Bot einen Namen (z. B. Mein KI Assistent)
  4. Wähle einen Benutzernamen, der auf bot endet (z. B. mein_gemini_ki_bot)
  5. Kopiere den angezeigten HTTP API Token (sieht aus wie 123456789:ABCdef...)
2

Kostenlosen Gemini API-Schlüssel holen

Google stellt die Gemini Flash Modelle im Free Tier kostenlos bereit:

  1. Gehe zu Google AI Studio API Keys
  2. Melde dich mit deinem Google-Konto an
  3. Klicke auf "Create API key" und kopiere deinen neuen Schlüssel
3

Tokens eintragen

Öffne links im Datei-Explorer die Datei .env und trage deine Schlüssel ein:

GEMINI_API_KEY=dein_gemini_schlüssel_hier
TELEGRAM_BOT_TOKEN=dein_telegram_token_hier

Nach dem Speichern verbindet sich der Server automatisch mit deinem Bot!

4

In Telegram chatten

Suche deinen Bot in Telegram, drücke Start und stelle ihm Fragen – Gemini antwortet sofort!
